# app-gtg

Public web pages for the DriveAway GTG app, served by GitHub Pages at https://gtg.mygig.life/.

- `privacy/index.html`, `terms/index.html`: copies of `docs/legal/privacy.html` / `terms.html` from the app repo, which are
  generated from the in-app text (the app's `LegalPagesTest` keeps them in sync). Copy them here whenever they change.
